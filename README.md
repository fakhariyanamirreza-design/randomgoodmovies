# ربات انتشار فیلم رندوم در کانال تلگرام

این پروژه هر ۲ روز یکبار به‌صورت خودکار:
1. طبق پروفایل‌های تعریف‌شده در `config.json` یک فیلم رندوم از TMDb انتخاب می‌کند.
2. یک متن معرفی کوتاه و فکت‌محور (امتیاز، ژانر، کارگردان، خلاصه) می‌سازد.
3. پوستر رسمی فیلم را می‌گیرد.
4. لینک IMDB را ضمیمه می‌کند.
5. همه را به کانال تلگرام شما ارسال می‌کند.
6. فیلم را در تاریخچه ثبت می‌کند تا دوباره تکرار نشود.

همه‌چیز **رایگان** است: TMDb API رایگان، Telegram Bot API رایگان، و اجرا روی GitHub Actions
(پلن رایگان GitHub برای این حجم کار کاملاً کافی است).

---

## چیزهایی که خودت باید یک‌بار انجام بدی (حدود ۱۵-۲۰ دقیقه)

### ۱. ساخت ربات تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` را بزن و اسم و یوزرنیم دلخواه بده.
3. یک توکن به شکل `123456:ABC-DEF...` می‌گیری — نگهش دار (`TELEGRAM_BOT_TOKEN`).
4. ربات را به کانالت (به‌عنوان **ادمین**) اضافه کن (فقط نیاز به دسترسی "ارسال پیام" دارد).
5. آیدی کانال را بگیر:
   - اگر کانال پابلیک است: همان `@yourchannel` کافی است.
   - اگر پرایوت است: یک پیام در کانال فوروارد کن به [@userinfobot](https://t.me/userinfobot) یا از API گتاپدیتز استفاده کن تا عددی شبیه `-1001234567890` پیدا کنی.
   - این مقدار می‌شود `TELEGRAM_CHANNEL_ID`.

### ۲. گرفتن کلید TMDb (رایگان)
1. در [themoviedb.org](https://www.themoviedb.org/signup) ثبت‌نام کن.
2. برو به Settings → API → Request an API Key (نوع Developer را انتخاب کن).
3. یک "API Key (v3 auth)" می‌گیری — همین می‌شود `TMDB_API_KEY`.

### ۳. بالا بردن پروژه روی GitHub
1. یک ریپازیتوری جدید (می‌تواند Private باشد) در گیت‌هاب بساز.
2. محتوای همین پوشه را push کن.
3. برو به Settings → Secrets and variables → Actions → New repository secret و این سه مقدار را اضافه کن:
   - `TMDB_API_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHANNEL_ID`

### ۴. تست دستی
- در تب **Actions** ریپازیتوری، روی workflow به اسم `Publish Random Movie` بزن و
  گزینه‌ی **Run workflow** را انتخاب کن تا همین الان یک بار به‌صورت دستی اجرا شود.
- اگر همه‌چیز درست باشد، چند ثانیه بعد یک پست در کانالت می‌بینی.

از این به بعد هر ۲ روز یکبار (طبق زمان‌بندی داخل `.github/workflows/publish.yml`) خودش اجرا می‌شود؛ دیگر
نیازی به هیچ کار دستی نیست.

## چطور شاخص‌های انتخاب فیلم را تغییر بدهم؟

فایل `config.json` را باز کن. هر آبجکت داخل لیست `profiles` یک "دسته" است. اسکریپت هر بار
یکی از این دسته‌ها را رندوم انتخاب می‌کند و داخل همان دسته یک فیلم رندوم پیدا می‌کند.
می‌توانی دسته اضافه/حذف/ویرایش کنی، بدون اینکه به کد دست بزنی.

پارامترهای قابل استفاده در هر پروفایل:
| کلید | معنی |
|---|---|
| `with_genres` | کد ژانر (جدول زیر) |
| `vote_average_gte` | حداقل امتیاز (از ۱۰) |
| `vote_count_gte` | حداقل تعداد رأی (برای فیلتر فیلم‌های ناشناخته/کم‌رأی) |
| `release_date_gte` / `release_date_lte` | بازه‌ی زمانی اکران |

### جدول کد ژانرها (TMDb)
| کد | ژانر | کد | ژانر |
|---|---|---|---|
| 28 | اکشن | 14 | فانتزی |
| 12 | ماجراجویی | 36 | تاریخی |
| 16 | انیمیشن | 27 | ترسناک |
| 35 | کمدی | 10402 | موزیکال |
| 80 | جنایی | 9648 | معمایی |
| 99 | مستند | 10749 | عاشقانه |

| 10751 | خانوادگی | 53 | هیجان‌انگیز |

می‌توانی چند کد ژانر را هم با کاما بنویسی، مثلاً `"with_genres": "28,12"`.

بعد از تغییر `config.json`، فقط کافیست commit و push کنی — دفعه بعدی که workflow اجرا شود
از تنظیمات جدید استفاده می‌کند. نیازی به هیچ کار دیگری نیست.

## نکات و مسیرهای توسعه بعدی (اختیاری)
- **زمان‌بندی**: خط `cron` در `publish.yml` قابل تغییر است (فرمت استاندارد cron، به وقت UTC).
- **برندینگ عکس**: در نسخه فعلی از پوستر اصلی TMDb استفاده می‌شود. اگر بخواهی لوگوی کانال یا
  بج امتیاز روی پوستر اضافه شود، می‌توانیم بعداً یک مرحله‌ی Pillow برای overlay اضافه کنیم.
- **متن با لحن دیگر**: اگر بعداً خواستی متن‌ها را به سبک طنز/تحلیلی عمیق‌تر بسازی (به‌جای فکت‌محور فعلی)،
  می‌شود یک مرحله‌ی تولید متن با LLM اضافه کرد — چون آن حالت هزینه API دارد، الان کنار گذاشته شده.
- **جلوگیری از تکرار**: تاریخچه در `data/posted.json` نگه داشته می‌شود و توسط خود workflow
  در ریپازیتوری commit می‌شود؛ نیازی به دیتابیس جدا نیست.
